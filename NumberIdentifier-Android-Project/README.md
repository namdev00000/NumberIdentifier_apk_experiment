# Number Identifier Android App

Version 1 of the Number Identifier app, written in Kotlin.

## Current features

- Accepts integer input.
- Identifies Natural, Whole, Integer, Rational, Irrational, and Real classification.
- Reports Positive/Negative/Zero.
- Reports Even/Odd.
- Checks Prime/Composite.
- Includes a starter GitHub Actions workflow for a debug APK.

## Natural number convention

This version uses Natural Numbers = {1, 2, 3, ...} and Whole Numbers = {0, 1, 2, ...}.

## Build

Open the project in Android Studio and let Gradle sync. Then use the Android Studio Run action or build with Gradle.
